# haruharu-pay

`pay.haruharu.co.kr` (`haruharu-pay.pages.dev`) 참가비 송금 페이지.

- Cloudflare Pages 프로젝트 `haruharu-pay`
- `main` 에 push 하면 자동 배포 (Actions `deploy`)
- 원본은 `index.html` 하나. 금액/돌아갈 폼은 그 안 `CELLS` 표에서만 고침
- `./build.sh` 가 `/g/ /t/ /r/ /s/ /c/ /a/ /j/ /e/ /f/` 와 `404.html` 로 복사함. CI 도 배포 전에 돌림
- 신청폼이 `/j/`(일반) `/e/`(사전알림), `/jnu-festival/` 이 `/f/`(전남대 축제 4,900) 를 씀 → 금액 바꿀 땐 join 폼이랑 같이 맞출 것

- `/d/`: 서울·광주 별도 할인 신청폼 참가비 4,900원. 일반 `/j/`와 안내가 같으며 금액만 다름.
- `/b/`: 친구 할인 5,900원(2026-10-08~). join 개선판 정가 폼(`/4/seoul/v2/`, `/4/gwangju/v2/`)에서 친구와 같이 신청한 사람이 이 금액으로 송금함. 일반 `/j/`와 안내가 같으며 금액만 다름.
- `/k/`: 재참여 설문 + 친구 할인 3,900원(2026-10-17~). join 재참여 후기 폼(`/rejoin/seoul/`)에서 후기를 남기고 참여하면서(5,900원) 친구와 같이 신청한 사람이 이 금액으로 송금함. 일반 `/j/`와 안내가 같으며 금액만 다름.

- `/m/`: 8·9기 일반 신청폼 남성 참가비 10,000원. `/mf/`: 남성 친구 할인 8,000원. 여성은 `/j/` 7,900원, `/b/` 5,900원 유지. 이 두 경로를 신청폼보다 먼저 배포한다.
